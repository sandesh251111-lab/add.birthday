# ADDRINA Birthday Website

A personalized birthday website from Uncle Sandesh, built with HTML, CSS and JavaScript.

## Files
- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — Nepal-time countdown, birthday reveal and confetti
- `images/addrina-collage.jpg` — the collage you supplied
- `birthday-guitar.mp3` — add your guitar instrumental audio here

## Add the guitar audio
Place a guitar instrumental you created or have permission to use in this folder and name it `birthday-guitar.mp3`.

The page attempts to play it automatically at midnight. Modern browsers may block autoplay with sound until the visitor interacts with the page; websites cannot override that browser policy.

## Birthday date
Currently set to November 13, 2026 at 12:00 AM Nepal time (UTC+05:45), in `script.js`.

## Publish using GitHub Pages
1. Create a GitHub repository named `addrina-birthday`.
2. Upload all files and folders, preserving the structure.
3. Open Settings → Pages.
4. Choose Deploy from a branch, select `main` and `/(root)`, then Save.
